# Spark Batch Monitor

Humanlike auto-accept for Spark batches. Zero ban risk.

## Features
- ✅ Humanlike auto-accept (configurable delays)
- ✅ Real GPS location (no spoofing)
- ✅ Intelligent filtering (money, miles, items)
- ✅ iOS app with toggle controls
- ✅ Professional monitoring

## Setup

### Backend (Render)
1. Clone repo
2. Set environment variables:
   - SPARK_EMAIL
   - SPARK_PASSWORD
3. Deploy to Render

### iOS App (Xcode)
1. Open SparkMonitor app in Xcode
2. Update backend URL in Settings
3. Build and run on real iPhone

## Safety
- Manual accept recommended
- Auto-accept delays: 1500-3000ms
- Real GPS location required
- Complete batches for good rating
